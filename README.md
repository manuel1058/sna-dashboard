# sna-dashboard

SNA 광고 운영 허브. 업체별 매체 운영 현황과 광고 성과를 한 화면에서 확인하는 웹 앱입니다.

- **운영 현황**: 마스터 시트의 `업체x매체현황` 탭을 읽어 라이브/멈춤 상태를 보여 줍니다.
- **광고 성과**: 마스터 시트의 `통합DB` 탭(일자, 업체, 매체, 노출, 클릭, 광고비, 전환, 매출)을 읽어 업체별/매체별 성과를 보여 줍니다. 탭이 없으면 안내 화면이 나옵니다.
- 로그인: 팀원이 각자 구글 계정으로 로그인하며, 앱은 **읽기 전용** 권한만 요청합니다. 시트 권한이 없는 계정은 데이터를 볼 수 없습니다.
- 데모: 주소 끝에 `?demo=1`을 붙이면 로그인 없이 가짜 데이터로 화면을 볼 수 있습니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 틀 |
| `style.css` | 디자인 |
| `config.js` | 설정 (구글 로그인 CLIENT_ID, 시트 ID, 탭 이름) |
| `data.js` | 데이터 읽기 계층 (시트 소스 / 데모 소스). 나중에 DB로 바꿀 때 이 파일만 교체 |
| `app.js` | 로그인과 화면 |

## 보안 원칙
- 비밀번호, API 키, 토큰을 이 저장소에 넣지 않습니다.
- `CLIENT_ID`는 공개되어도 되는 식별값입니다.
- 구글 로그인 토큰은 브라우저 메모리에만 보관하며 저장하지 않습니다.
